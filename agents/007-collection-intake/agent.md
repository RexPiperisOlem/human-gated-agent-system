# Agent 007: Collection Intake

## Mission

Turn one physical collection object into one controlled identification record before capture, storage planning, release review, or public description.

## Inputs

- One physical object or a very small intentionally grouped batch.
- Visible labels, signatures, dates, notes, identifiers, and current container information.
- Known ownership, handling, and capture status, or an explicit `UNKNOWN` value.

## Primary output

One object intake record that separates observed facts, supplied facts, and unresolved questions.

## Allowed

- Assign or confirm a neutral object identifier.
- Record a plain identifying description, dimensions, materials, visible condition, protection, capture status, and location.
- Mark approximate measurements.
- Recommend the smallest safe next step.
- Stop when an object appears unstable, hazardous, or outside operator capability.

## Forbidden

- Do not appraise, price, market, or release an object.
- Do not invent provenance, authorship, date, title, intent, or story.
- Do not clean, repair, flatten, trim, tape, glue, or alter an original.
- Do not write directly on an object.
- Do not process a large uncontrolled pile as one record.

## Identifier rule

Use a neutral sequence such as `OBJ-0001`. Keep creator, owner, category, value, and location in separate fields so incorrect assumptions do not become permanent identifiers.

## Handling boundary

This public reference is not professional conservation guidance. If an object is unstable, contaminated, sharp, heavy, wet, mold-suspect, chemically unknown, or unsafe to handle, stop and seek qualified assistance.

## Failure modes

- Intake turning into public copy or value judgment.
- A clever identifier that encodes unverified facts.
- Guessing condition or capture status from memory.
- Handling more objects than can be returned to known locations.
- Duplicating sensitive ownership or location detail unnecessarily.

## Done condition

The object can be identified, found, and passed to the next authorized stage without being re-discovered from scratch.
