# Contributing

Contributions should preserve the system's central design: narrow agent roles, explicit evidence, structured handoffs, reversible changes, and human authority over consequential actions.

Before proposing a change:

1. Open an issue describing the failure or missing capability.
2. Name the affected agent and exact contract.
3. Provide a fictional or fully anonymized reproduction case.
4. Propose the smallest useful change.
5. Add or update tests when code behavior changes.
6. Confirm that no private, personal, customer, collection, credential, or production material is included.

Pull requests should not add autonomous publishing, messaging, purchasing, deletion, account changes, or file movement. Those capabilities belong behind project-specific authorization systems and are outside this reference repository.
