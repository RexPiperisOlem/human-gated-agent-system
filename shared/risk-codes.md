# Risk Codes

| Code | Use when |
| --- | --- |
| `SOURCE_MISSING` | A required source or control document is absent. |
| `SCOPE_DRIFT` | Output moves beyond the approved purpose. |
| `UNSUPPORTED_CLAIM` | A factual claim lacks evidence or clear qualification. |
| `FORMAT_MISMATCH` | The deliverable does not match the required format or package. |
| `FILE_INTEGRITY` | A file is missing, unreadable, corrupted, or incorrectly identified. |
| `AUTHORITY_MISSING` | The required human decision has not been recorded. |
| `PRIVACY` | Personal, confidential, customer, collaborator, or restricted data may be exposed. |
| `INTELLECTUAL_PROPERTY` | Ownership, license, attribution, or derivative-use rights are unclear. |
| `HIGH_STAKES` | Legal, medical, financial, physical-safety, or similarly consequential review is required. |
| `ACCESS_BURDEN` | The workflow creates avoidable physical, cognitive, or technical burden. |
| `STYLE_MISMATCH` | Output violates the selected style profile or audience boundary. |
| `VERSION_CONFLICT` | Multiple records claim incompatible current states. |
| `ROLE_CONTAMINATION` | An agent performed work assigned to another role. |
| `EXTERNAL_ACTION` | The task implies publishing, sending, purchasing, account change, or another real-world action. |
